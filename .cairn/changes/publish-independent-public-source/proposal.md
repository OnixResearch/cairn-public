# Proposal

## Why

The reviewed independent Cairn base retains private active Artifact and historical producer coordinates. Anonymous source publication needs exact independent public pins without changing native actor semantics, frozen proof bytes, license-grant anchors, or lifecycle authority.

## What Changes

- Bind Cargo/Nix to independent public Artifact and Bounded Exec snapshots and observed NAR identities.
- Preserve the historical Slotcar producer through its reviewed public export; use its actual package/config contract rather than upgrading to the new Octet compiler.
- Make Nickel-export's validation-only Cairn input follow this assembly, eliminating its private Cairn/Slotcar closure without disabling checks.
- Keep Nickel exactly 1.17.0 and all existing public third-party/Kiln/Cap Root/Durable File/Mantle pins.
- Refresh source-selection documentation and the producer integration requirement; retain the historical `octet` input/check key.

## Non-Goals

No runtime feature, native actor implementation, signing behavior, historical receipt relabelling, original private repository/history publication, package release, or release admission.

## Success Criteria

The immutable assembly can be anonymously fetched with exact public dependency sources. The parent builds a real CLI once and replays the preserved signed synthetic fixtures. Source-pin positive and negative boundaries remain strict. Lifecycle completion requires fresh parent-owned checks, sync, archive, branch push and verified fast-forward integration.
